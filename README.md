A web-based Car Rental Management System designed to streamline booking, customer management, car inventory tracking, and admin operations.

🚗 Features

User registration & login

Car browsing and availability checks

Car booking and rental request management

Admin dashboard for:

Managing car inventory

Viewing bookings

Approving/rejecting rental requests

Secure authentication

Simple, responsive UI

🛠️ Tech Stack

Frontend:  JSP / HTML / CSS

Backend: Java (Spring Framework)

Database: SQL Server

Version Control: Git/GitHub
